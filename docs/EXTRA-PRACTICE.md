# 隨時加練 HRP、Plank 與兩英里跑

訓練頁直接提供三個入口，不受星期或 Boss 輪替限制，不需先跑整套十動作暖身；使用者自行完成暖身後開始。

- HRP：2 分鐘倒數，自行計數後明確儲存成績。
- Plank：由零正向計時，結束後確認秒數。
- 兩英里跑：自行完成距離並計時，輸入分秒；站內跑姿求助保留草稿。

沿用現有 Boss 的求助、暫停、重載恢復與失敗重試機制，但加練僅追加既有格式的 PR 紀錄。今日課表完成狀態、session、課表 XP、連續天數及每週測驗輪替不受加練影響。避免把額外練習誤當完整今日課表。

加練在獨立暫存 checkpoint 以選填 `practice:true` 辨識；舊 checkpoint 缺欄位時維持測驗行為。已有進行中的訓練／測驗時不可用新加練覆蓋。未明確儲存不追加成績，取消清理暫存；重載、求助與儲存失敗不重建計時或重複追加 PR。主資料的 schema 與 PR 格式不變。

實際驗收結果以 reports/qa-extra-practice-* 及正式站報告為準；此文件描述本輪交付行為，不代表尚未完成的測試已通過。
