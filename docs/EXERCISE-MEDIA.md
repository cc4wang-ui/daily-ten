# 離線動作影片交付規格

目前 `js/ui/exercise-media.js` 的正式影片清單為空；**0 個完整真人影片**。另有十九套 AI 生成的 16 格連續影格，對應標準與跪姿伏地挺身、控制深蹲、深蹲蹲坐、臀橋、腳底固定彈力帶划船、貓牛式及 90/90 髖旋轉、踩腳彈力帶肩上推與羅馬尼亞硬舉、原地快走、側步開合、左右分腿蹲及前臂平板支撐的精確名稱。它們是可逐格操作的站內示範，不是完整真人影片。

2026-10-13 使用者明確決定由自己判斷示範動作，不再以外部運動專業審核作為本輪發佈條件。仍需確認影格清楚、對應變式正確、素材可離線使用，並如實顯示尚缺完整影片的動作。

前八套影格由內建 ImageGen 產生，均為固定視角、灰衣深色短褲成人、4×4 順序影格。前四套提示要求標準伏地挺身下降及撐起、控制深蹲下降與站起、臀橋上抬與下放，以及彈力帶繞過雙腳腳底的坐姿划船拉放；新增四套提示要求四足跪姿的貓牛式脊椎屈伸、膝蓋全程著地的跪姿伏地挺身、坐姿 90/90 左右髖旋轉，以及深蹲到底部後延長停留再站起。使用者可播放、暫停、慢速、拖曳逐格與重播。控制深蹲的 16 格節奏約為 3 秒下降、1 秒站起；深蹲蹲坐加長底部影格。原始產物保留在 ImageGen 輸出目錄，App 使用 `media/exercises/` 的本地副本。鴿式候選影格未清楚呈現左右換側，因此未納入 App。

2026-10-18 另外加入四套免固定點／雨天影格，肩上推與硬舉循環 3 秒，快走與側步循環 2.4 秒。這些循環是示意，並不計算使用者次數。圖片由內建 ImageGen 生成與修改，播放器保留原始長寬比例；提示與選稿紀錄見 [本輪來源](./MOTION-PROMPTS-2026-10-18.md)。

2026-10-19 加入左右分腿蹲各一套及前臂平板支撐，共十五套、精確名稱 38/73。分腿蹲每次循環約 3 秒；前臂平板示範包含進入、延長保持與退出，不以影格循環當作訓練秒數。[本輪提示與來源](./MOTION-PROMPTS-2026-10-19.md)。死蟲式候選因對側手腳順序不清楚退件。

[精確名稱覆蓋清單](../reports/exercise-media-coverage.md) 由目前所有等級、有帶／無帶課表、保底、雨天與 Boss 測驗產生。改課表或登錄影片後執行 `npm run report:media`，CI 的 `npm run check:media-coverage` 會檢查清單是否過期、是否有失效或重複的影片名稱。缺片數是示範覆蓋率指標，不會因測試通過就當成已交付完整影片。

[候選影片清單](../reports/media-candidates-2026-10-13.md)只列出可供逐片審查的來源；目前沒有任何候選通過驗收，也沒有加入正式播放器。

2026-10-19 本輪新增彈力帶開肩、踩腳側平舉、俯臥 Y 舉與 T 舉四套 AI 16 格影格，共十九套本機 PNG。普通循環 3 秒；慢速 T 舉採同素材、獨立 4 秒節奏。精確覆蓋 45/73，仍缺 28 個名稱；完整真人影片仍為 0。開肩只由雙手持帶，側平舉踩腳固定，不需居家外部固定點。Y／T 保持胸腹接地、小幅抬臂，有輕微逐格比例漂移，不能稱為真人影片。快取 v25。

## 取得影片

優先拍攝或委製本課表的動作。攝影時按課表的確切變式、器材與阻力、左右側、強度等級錄製；取得可離線散布及改剪的書面權利。若採開放授權素材，逐檔保存作者、原始頁、授權版本、所作修改與 App 中的署名。Wikimedia Commons 有[運動影片分類](https://commons.wikimedia.org/wiki/Category:Videos_of_physical_exercises)，但數量與變式不保證覆蓋課表；[各檔授權及署名要求不同](https://commons.wikimedia.org/wiki/Commons:Reusing_content_outside_Wikimedia/en)。例如 [Burpee.webm](https://commons.wikimedia.org/wiki/File:Burpee.webm) 是一段可評估的候選影片，**尚未審核，也不能直接當本課表示範**。YouTube 搜尋結果不能充當離線素材；[YouTube API 政策限制未獲許可時下載、快取及離線播放](https://developers.google.com/youtube/terms/developer-policies)。

## 每個動作的驗收紀錄

1. 固定 `movementId`，列出課表中完全相同的 `names`。一個影片只涵蓋已核對的變式；左右側、跪姿、慢速、彈力帶固定方式與其他不同動作逐一判斷，不能用名稱前綴自動套用。
2. 影片至少有清楚的起始、離心、底部或終點、向心及結束姿勢，能看出完整活動範圍、速度、呼吸或用力時機。需要時提供前面與側面視角，完整循環可重播、暫停及慢速查看。短片或 GIF 若缺少這些關鍵階段，不合格。
3. 隨片提供起始姿勢、器材擺法、動作範圍、常見代償、停止條件與可用替代。逐字核對現行課表說明及劑量，確認沒有誤示不可靠固定點。
4. 由具運動專業資格的人員逐片檢查。紀錄姓名、資格、審核日期、審核結果與權利來源；退件片不得設 `reviewed: true`。剪輯、重拍或課表動作變更後重新審核。
5. 將通過的 MP4 或 WebM 放入 `media/exercises/`，在 `EXERCISE_MEDIA` 中登錄確切名稱、本機路徑、`reviewed: true` 和上述 reviewer/rights 欄位。建置時檢查檔案存在、每個正式課表動作恰好對到一片、檔案可解碼；把通過的檔案加入 Service Worker 預快取並更新快取版本。
6. 在 iPhone 主畫面 App 飛航模式下逐片測試播放、載入失敗提示、暫停/續播、求助後返回原步驟與剩餘秒數。任何缺檔或錯誤都應顯示「無法載入」，不能回退成完整教學的假象。

目前可由程式驗證「只有登錄、確切匹配、經審核的本機路徑才會進播放器」；專業動作審核、授權核對與真機解碼仍須在素材到位後完成。`node --test tests/exercise-media.test.mjs` 檢查查表與缺片狀態。
