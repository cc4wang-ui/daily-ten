# 彈力帶阻力標記

同一個肩上推動作，換帶子或握距就可能改變難度。主觀難度與次數不能直接比較不同設定，本輪用自訂文字標記分開記錄，而不是推測公斤或帶子顏色的強弱。

編號工作組的彈力帶肩上推、划船與羅馬尼亞硬舉，可在回報時選填最多 40 字標記，例如「紅帶／握短一格」。同變式下一組會預填最近有效標記；留白代表未記錄，徒手動作維持原回報。

次數目標只使用今天以前、近 28 日的同變式紀錄；阻力標記需相同，且完整組號、實際次數、難度、姿勢與既有條件仍需達標。兩個可用完整訓練日後才依原規則 +1，下限基準、上限基準 +2 與變式上限不變。新標記不借用未標記或其他標記的成功紀錄；同日混用標記不能拼出一套完整成功證據。

今天新填或改標記不重算今天的目標，正在進行的 checkpoint 保留當堂序列；下一遊戲日才採用新的歷史設定。回到以前的相同標記，可使用視窗內該設定的有效證據。標記由使用者自行保持一致，不能量測實際阻力、握距或活動範圍。

資料使用既有 `game.trainingFeedback[]` 的選填 `resistance` 欄位，沒有新增必填資料或升版本。舊備份不補造標記；新欄位要能隨備份往返，無效欄位不能截斷或悄悄改成未記錄來供應成功證據。實際相容性與回歸結果以本輪 QA 為準。
