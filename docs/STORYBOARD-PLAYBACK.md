# 原始姿勢與播放順序

每份影格圖的frames是來源格數（8或16），不是獨特動作角度數或影片張數。沒有playbackOrder的舊圖維持依格循環；有明確順序時才依index播放。frameMs與實際播放步數一致，不與來源張數混淆。

提踵三圖為4×2、8個來源姿勢。向上0到7後，沿6到1原路返回，共14步、2秒；肩外旋為4×4、16個來源姿勢，0到15再14到1，共30步、3秒。這些單一動作的回程走相同姿勢路徑，逆放只用於已核對的對稱路徑，不套用跑步等完整步態。介面分別標示來源姿勢及往返步數，不說14／30個獨特影格。

逐格滑桿選來源格，播放時依目前順序更新；暫停、半速、重播與關閉清理一致。圖片單格比例由(W/columns)/(H/rows)計算；4×2圖不會拉寬為整張圖比例。無效空陣列、稀疏陣列、超界index、遺漏來源、非0起點或時間長度不符一律拒絕，不以猜測補成可播放。

素材是原創AI影格，YouTube僅作動作路徑參考，沒有把第三方影片下載重包進App。雙腳與單腳提踵參考Margaret Martin物理治療師示範：https://www.youtube.com/watch?v=FRw-Oe7wcSY （雙腳2:57–3:09、單腳4:49–4:54）。肩外旋參考stoneclinicPT：https://www.youtube.com/watch?v=sL7fvQ2DuGE （1:08固定帶、1:29外旋、1:31返回），以另一手在腹前固定，無居家外部錨點。來源、實際觀看紀錄與所有淘汰稿在MOTION-PROMPTS-YOUTUBE-* JSON。

死蟲式為16個來源格，依0–7、6–0回中位，再8–15、14–8回中位，共30步、6秒，橙色左腕與右踝、藍色右腕與左踝表示對側配對。端點重複保留受控停留；不是30個獨特姿勢。參考Pursuit Physical Therapy：https://www.youtube.com/watch?v=o4GKiEoYClI （0:11、0:14–0:17）。

跑步依16格原順序循環，沒有逆放；只示意交替步態，不代表2英里測驗速度、距離或自動計次。參考Mayo Clinic Health System：https://www.youtube.com/watch?v=FHn_t8NPBhg （0:48後方交替、1:06側面跨步分析）。最終稿修正鞋色與對側擺臂，淘汰同腳領先及手臂固定的舊稿。
