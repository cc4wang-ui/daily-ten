# 無帶拉日精簡 · 2026-10-22

新課表移除「毛巾直臂下拉」兩組及其組間休息，不加另一個湊數項目。原名稱與屈肘口令矛盾。仍保留超人式划船兩組、慢速俯臥T舉與核心，主題維持低阻力上背控制，不能等同負重拉。

參考 Tanimoto 等的原始研究：[Biomechanics 2025, 5(2),33](https://doi.org/10.3390/biomechanics5020033)。研究的自我阻力毛巾下拉是雙手向外拉緊，同時屈肘下移的動作；急性量測偏向後三角肌與三頭肌負荷，背闊肌活動低於機械下拉。作者表示長期訓練效果尚未知。此依據不支持把它稱為直臂或負重拉等效替代；本次採產品精簡，不照搬研究處方。

移除只作用於之後建立的新課表。已儲存的舊checkpoint仍保留整份序列、索引、次數與名稱，不重建、不把舊動作換成新動作、不自動記完成。舊動作的文字說明會標明已移除；使用者可沿既有求助路徑略過，沒有圖時不借別的變式影格。

主課表預估仍由實際序列加總，少掉的工作組與休息自然扣除，不硬寫新的總時長。彈力帶版課表與進階證據規則不變。
