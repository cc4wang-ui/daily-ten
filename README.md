# Daily Ten

2026-10-19 本輪新增彈力帶開肩、踩腳側平舉、俯臥 Y 舉與 T 舉四套 AI 16 格影格，共十九套本機 PNG。普通循環 3 秒；慢速 T 舉採同素材、獨立 4 秒節奏。精確覆蓋 45/73，仍缺 28 個名稱；完整真人影片仍為 0。開肩只由雙手持帶，側平舉踩腳固定，不需居家外部固定點。Y／T 保持胸腹接地、小幅抬臂，有輕微逐格比例漂移，不能稱為真人影片。快取 v25。

設定頁有「有彈力帶」開關；關掉後改用毛巾與徒手替代動作，但徒手拉力不足以等效取代有阻力的拉動作。

## 課表結構

週一至五是「五個活動度動作＋當日重點區塊」；週六恢復、週日 Boss Day。區塊與活動度組由星期決定。
主課表時長由每個動作的次數×節奏、停留、休息與換器材時間加總，隨等級及器材條件改變。週日只顯示暖身時長，測驗另計。

| 日 | 內容 | 伸展組 |
|---|---|---|
| 一 · 四 | 活動度＋推與肩 | A／B |
| 二 | 活動度＋下肢與髖伸 | B |
| 三 | 活動度＋拉與上背（加練日） | C |
| 五 | 活動度＋短版下肢與拉力補強 | A |
| 六 | 恢復日：三組伸展全走，不做肌力 | C |
| 日 | Boss Day：十動作＋AFT 測驗 | A |

伸展組 **A** 髖與後鏈／**B** 胸肩與上背／**C** 全身流動，五個槽位固定、內容輪替。

今日頁的「下一步」會依時間帶你做早安打卡、今日課表或週日 Boss Day。訓練分頁有三種劑量：保底版、今日課表、加一輪加強區塊；另有原地快走＋側步的低衝擊雨天／出差替代。組間休息可加 20 秒並隨檢查點保存。

### 漸進超負荷

目前先用可控制的動作範圍、保留約 2 下餘力與輕阻力彈力帶。自動課表已移除疲勞後的跳蹲與假直立伏地挺身；訓練中可回報每組實際次數、難度、姿勢與疼痛。疼痛或姿勢不穩會停止訓練且不記完成，近期不佳回報會擋住升級。手動強度升級還要求近七日推、負重拉、蹲、髖伸各有兩天至少兩組的達標回報；舊紀錄不會被推定為達標，無帶上背控制不計負重拉。主課表的編號力量工作組會依同變式近期回報調整次數：兩個完整訓練日都輕鬆達標，每組增加 1 下，最多高於本級基準 2 下；吃力或未達標等回報會重設到基準。訓練分頁顯示每個動作的基準、本次目標與原因。降量日不自動增加，正在進行的課表維持固定序列。這只調整次數，尚未依各肌群週量、彈力帶阻力或活動範圍改處方。規則與限制見 [個別動作進階](./docs/TRAINING-PROGRESSION.md)。

彈力帶用腳底踩穩，不用門錨或牆；它提供水平拉阻力（划船）與肩上推阻力。無帶版只做低阻力上背控制，不能視為等效的負重拉力訓練。

## 動作示範

舊線條動畫已從訓練與求助畫面隱藏。標準與跪姿伏地挺身、控制深蹲、深蹲蹲坐、臀橋、腳底固定彈力帶划船、貓牛式、90/90 髖旋轉、踩腳彈力帶肩上推與羅馬尼亞硬舉、原地快走、側步開合、左右分腿蹲及前臂平板支撐已有 AI 生成的 16 格連續影格；它們可離線播放，但不是完整真人影片。正式離線影片清單目前仍為空：

- **訓練中**：開啟 App 內說明時倒數暫停，關閉後回到同一步與剩餘時間；缺片時可在視窗內略過當前實際動作，該次不記完成或 XP。

- **訓練分頁 › 動作庫**：有連續影格的動作可在站內播放、慢速、逐格及重播；其他動作顯示缺片狀態。外部 YouTube 搜尋仍需連網。 影格載入中會顯示狀態，失敗或等候超過 15 秒可原位重試；載入成功前不啟用播放控制。

## 身體指標（統計 › 身體指標）

體重 / 腰圍 / 靜息心率 / 睡眠每天記，圍度雙週，肌力檢測每月。
前後各 7 天都有體重紀錄時，App 以兩個 7 日均與腰圍方向判讀增重趨勢。心率警示使用近 3 天均值與歷史基線；其他規則（例如睡眠 3 天不足）是畫面上的手動參考，App 不會自動改課表或熱量。
巨量營養素以最新體重及 g/kg 計算；熱量以體重 kg × (33–37) + 250 kcal 作起點估算，需由後續趨勢校準。

## 早安打卡與遊戲規則（V1）

- **早安打卡**：04:00–12:00 開放。點一下「我起床了」＝記錄起床（按下的時間，可往前改）＋確認昨晚熄燈（預填就寢目標，可改）；10 秒內可復原。一個遊戲日一筆。
- **計分**（D18 漸進，每支柱每日上限 60）：起床在時段內 30／超出 30 分鐘內 15／之後 10；熄燈 20／10／5；睡滿 7 小時 10／差 30 分鐘內 5。動：保底版 30、主課表 50、加一輪 60、Boss Day 60。
- **XP 與等級**：XP 由訓練紀錄與打卡紀錄推導、每次重算；今日中央是總 XP 的遊戲等級「Lv N」（下一級需 200＋50×(Lv−1)），課表強度另稱「強度 L2」。
- **遊戲日**：04:00 換日，凌晨練的算前一天。
- **階段**：P1 睡飽（動＋眠）。近 14 天有 10 天起床在時段內＝P1→P2 條件達成；探索在 V4 開放，之前探卡顯示鎖定與進度。
- **Perfect Day**：當天已解鎖的支柱全完成（P1＝動＋眠，保底版也算）→ +30 XP，播一次慶祝卡（訓練中不打斷）。
- **升級卡**：中央 Lv 升級時跳出一次。
- **Freeze**：實際做滿 7 天得 1 張（最多 2 張）；漏掉的日子自動補上，連續天數不斷。
- **睡不夠自動降量**（D6）：睡不到 6 小時，或熄燈晚於時段 90 分以上 → 當天課表降一級，今日卡片一鍵恢復。
- **回歸任務**（D19）：中斷後第一個有完成的日子拿回歸徽章；3 天內有一天完成 2 項 → 當天 XP ×1.5。
- **90 天模擬**：`node tools/sim/run.mjs`（三種人設，10 條判準）。
- 數值都在 `data/game.json`（含每條規則的理由）；睡眠文字是一般性參考，不是醫療建議。

## 更新 App

**使用者不用做任何事**：新版上線後，App 在開啟或從背景切回時自動檢查，閒置時自動換成新版（訓練中不打斷），換完會短暫顯示「已更新到最新版」；SETUP 最下方顯示目前的 App 版本（D23）。離線時會在下次連線後更新。

開發者：改了 App 檔就把 `sw.js` 的 `CACHE = 'daily-ten-vN'` +1，新增的 App 檔加進 `ASSETS`（CI `check-repo` 會比對 main 檢查兩者）。
App 改用 ES modules，必須透過 http(s) 開啟（GitHub Pages 或 `npm run serve`），不能直接雙擊 `index.html`。

## 備份

資料只存在這台裝置的 localStorage，沒有雲端。

- **下載備份**：設定 → 資料備份 →「下載備份」，存成 `daily-ten-backup-YYYY-MM-DD.json`。iPhone 會跳出分享選單 →「儲存到檔案」。D27 起首頁不提醒，需要時手動用。
- **匯入**：「選擇備份檔匯入」或把 JSON 貼進文字框後按「匯入」。App 先驗證格式，壞檔只會顯示錯誤、不動現有資料；通過後先顯示「目前／匯入後」差異預覽，要按兩次確認才會覆蓋。
- **載入失敗保護**：資料讀不出來或格式異常時，原始內容會另存一份並在首頁顯示錯誤卡，可下載保存，App 不會白屏。
- 「匯出 JSON」（文字框複製）仍保留。
